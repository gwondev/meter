2. 배경
════════════════════════════════════════

  · 의류수거함·재활용함·폐의약품함 등 거점은 산재하고, 순회만으로는 사각지대
    (해안·외곽·옥상 등) 적재 상태를 제때 알기 어렵다.
  · 만재 여부를 모른 채 순회하면 공차·중복 방문이 늘고, 넘침·악취·민원 위험이 커진다.
  · 시민은 품목별 올바른 투입 거점을 찾기 어렵고, 운영자는 지도·알림·경로가
    한곳에 없는 파편화된 도구에 의존하기 쉽다.
  · 따라서 센서(초음파)·비전(카메라) IoT와 웹 관제·AI 안내를 하나의 플랫폼으로
    묶어, 상시 감시 → 최적 수거 → 자원순환 안내까지 잇는 것이 필요하다.


════════════════════════════════════════
3. 개발 목표
════════════════════════════════════════

  1) 사각지대 감시
     D모듈(초음파)·R모듈(카메라)로 거점 적재 상태를 상시 수집·표시한다.

  2) 최적 수거
     적재율(fillPercent) 기반 만재 우선 + 도로망 경로로 불필요 순회를 줄인다.

  3) 자원순환 안내
     AI(카메라·챗봇)로 품목 판별·투입 거점 안내를 제공한다.

  4) 통합 관제
     지도·모듈 현황·스냅샷·관리자·MQTT 진단을 웹 한곳에서 운영한다.

4. 모듈 종류 (한눈에)
════════════════════════════════════════

  ┌──────────┬─────────┬──────────────────────────────┬────────────────────┐
  │ 구분     │ 시리얼  │ 하는 일                      │ 적재율(fill%)      │
  ├──────────┼─────────┼──────────────────────────────┼────────────────────┤
  │ D모듈    │ m1,m2…  │ 초음파로 빈 높이 측정        │ 보드가 계산 후 MQTT│
  │ (모듈1)  │         │ ESP32 + HC-SR04P             │ 약 30초마다 전송   │
  ├──────────┼─────────┼──────────────────────────────┼────────────────────┤
  │ R모듈    │ r1,r2…  │ 용기 안을 내려다보는 카메라  │ 이미지만 MQTT      │
  │ (모듈2)  │         │ ESP32-CAM 등                 │ 서버 vision이 계산 │
  ├──────────┼─────────┼──────────────────────────────┼────────────────────┤
  │ POWER    │ (없음)  │ D·R 상시 전원(보조배터리 등) │ 통신 없음          │
  │ TANK     │         │ 파워케이스에 수납            │                    │
  └──────────┴─────────┴──────────────────────────────┴────────────────────┘

  ★ 공통 지표 fillPercent 0~100
      0 = 수거 불필요   ·   100 = 즉시 수거

  R모듈 한 줄
    치운 직후 사진 = original(원본) → 서버 baseline
    이후 사진 = sample(샘플) → 최근 10장과 원본 비교 → fill%
    (보드는 판정하지 않고 전송만 한다. METER.PDF 초안에는 R 서술 부족할 수 있음.)

5. 서비스 구성 (보고서용 · 비기술)
════════════════════════════════════════

  웹 지도        모듈 위치 · 적재율 · 신호 · R 최신 사진
  최적 수거 경로 화면 안 모듈 전부 방문 · 만재 우선 · 도로망
  AI 챗봇        모듈 DB 기반 자연어 질의
  AI 카메라      쓰레기 품목 분류 → 투입 위치 안내
  관리자         모듈·유저·더미 · R 사진(원본/큐/휴지통) · MQTT 진단


════════════════════════════════════════
6. 기대 효과
════════════════════════════════════════

  · 운영: 사각지대 적재를 원격으로 확인해 공차·중복 순회를 줄인다.
  · 환경: 넘침·불법 투기 예방에 기여하고 수거 효율을 높인다.
  · 시민: AI 안내로 올바른 분리·투입 거점을 쉽게 찾는다.
  · 확장: 의류·플라스틱·캔·폐의약품·물탱크 등 동일 지표(fill%)로 거점 확장 가능.
  · 기술: 초음파(D)와 비전(R)을 같은 관제 화면에서 통합 운영한다.
