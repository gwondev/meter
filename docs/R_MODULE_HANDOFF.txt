METER 모듈2 (R · 라즈베리파이) 인수 명세
갱신: 2026-09-02
분리 개발용 단권. 전체 맥락은 docs/DEVICE_SPEC.txt 참고.


목표
----
현장 카메라로 적재/오염 정도를 0~100%로 보고하고,
가능하면 현재 사진을 서버에 올리면 지도에 표시된다.


필수 계약
--------
  Base     https://meter.gwon.run
  POST     /api/device/modules/{serial}/report
  예       https://meter.gwon.run/api/device/modules/r1/report
  Header   X-METER-DEVICE-TOKEN: <토큰>
  Body     multipart: fillPercent + (선택) image
           또는 JSON: { "fillPercent": 72.5 }
  시리얼   r1, r2, …
  주기     5분

토큰은 서버 관리자가 METER_DEVICE_TOKEN으로 발급해 별도 채널로 전달한다.


하지 말 것
---------
  - MQTT를 필수로 쓰지 말 것 (사진은 HTTP만)
  - 시리얼을 m* 로 쓰지 말 것
  - 토큰을 깃에 커밋하지 말 것


스모크 테스트
------------
  curl -X POST "https://meter.gwon.run/api/device/modules/r1/report" \
    -H "X-METER-DEVICE-TOKEN: $METER_DEVICE_TOKEN" \
    -F "fillPercent=50" \
    -F "image=@./sample.jpg"

  200 + JSON ok:true 이면 연동 성공.
  웹 지도에 R 마커·적재율이 보여야 한다.


최소 Python 예
-------------
  import os, time, requests

  SERIAL = "r1"
  URL = f"https://meter.gwon.run/api/device/modules/{SERIAL}/report"
  TOKEN = os.environ["METER_DEVICE_TOKEN"]

  def capture_jpeg(): ...
  def estimate_fill(jpeg): ...   # 0~100

  while True:
      try:
          jpeg = capture_jpeg()
          fill = estimate_fill(jpeg)
          r = requests.post(
              URL,
              headers={"X-METER-DEVICE-TOKEN": TOKEN},
              data={"fillPercent": f"{fill:.1f}"},
              files={"image": (f"{SERIAL}.jpg", jpeg, "image/jpeg")},
              timeout=30,
          )
          r.raise_for_status()
          print(r.json())
      except Exception as e:
          print("report failed:", e)
      time.sleep(300)


오류 코드
--------
  400  fillPercent 누락·범위 초과
  401  토큰 불일치
  503  서버 토큰 미설정


선택 MQTT (비권장)
-----------------
  URI    ws://mqtt-meter.gwon.run:80
  Topic  meter/r1/status
  Body   { "moduleSerial":"r1", "fillPercent":72.5 }
  사진은 MQTT로 보낼 수 없음. HTTP가 본선.


연동 확인
--------
  [ ] METER_DEVICE_TOKEN 설정
  [ ] report 200 수신
  [ ] 지도에 R 마커·적재율 표시
  [ ] 12분 이상 미보고 시 신호 대기중
