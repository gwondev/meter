6. MQTT (디바이스 ↔ 서버)
────────────────────────────────────────

  URI (보드)   ws://mqtt-meter.gwon.run:80
  Topic        meter/{serial}/status
  Subscribe    meter/+/status  (backend)
  QoS          1 · retain false
  인증         없음 (현재)
  방향         디바이스 → 서버 발행만 (보드 subscribe 없음)
  HTTP 디바이스 API · METER_DEVICE_TOKEN 없음

  ── D모듈 (시리얼 접두어 m*) ──
  소스     meter_iot/src/module1.cpp
  보드     ESP32 + HC-SR04P (TRIG 32, ECHO 33), RGB 25/26/27
  주기     30초
  Payload  { "moduleSerial":"m1", "fillPercent":72.5 }
  레거시   heightCm → 서버가 depth(cm)로 fill% 환산
  시리얼 담당
    m1 (팀칭 d1)  성권 집 테스트 D
    m2 (팀칭 d2)  성권 제작 실 D
  ※ 백엔드 isDeviceSerial은 m*, r* 만 잠금. 팀 문서 d1/d2 = m1/m2.

  ── R모듈 (시리얼 접두어 r*) ──
  ※ R은 지정 구역을 반복 촬영하는 카메라다. 용기 내부를 내려다보는 장치가 아니다.
     해안·무단투기 구역·함 주변 지면처럼 바닥·경관이 바뀌는 곳을 본다.
  소스(테스트) meter_iot/module2/  (PlatformIO, LittleFS data/images)
  시리얼 담당
    r1  성권 집 테스트 R (프로토콜·서버·vision 검증)
    r2  수혁 제작, 좁은 구역용 소형 ESP 카메라
    r3  수혁 제작, 넓은 구역용 Raspberry Pi 5 고성능 카메라
  ※ 시리얼 충돌 금지.

  R 하드웨어 (구매품, 기구 모델링 기준)
    ※ 아래 치수는 공식 규격 기준. 호환품은 캘리퍼로 실측 후 모델 확정.

    r2  ESP32-CAM1 + OV2640, 4MB PSRAM (module2 펌웨어 board=esp32cam)
        구매       쿠팡 10,450원 (배송 3,000원)
                   「아두이노 ESP32-CAM1 OV2640 카메라 4M PSRAM 장착 보드」
        보드       약 40.5 x 27.0 x 4.5 mm (카메라·SD 제외)
        카메라     OV2640, FPC로 보드 상면에 고정 (렌즈 돌출 약 5~6 mm)
        기타       microSD 슬롯(짧은 변), 안테나(반대 짧은 변), 장착홀 없음
                   → 홈/레일로 끼우는 방식 권장
        업로드보드 ESP32-CAM-MB 결합 시 높이 약 +12 mm, 길이 약 +5 mm

    r3  Raspberry Pi 5 8GB 베이직 키트 (본체, 5V 5A 어댑터, HDMI, 전용 케이스, SD)
        보드       85 x 56 mm, PCB 약 1.6 mm, 최고 부품(USB·LAN) 약 16 mm
        장착홀     M2.5 4개, 홀 지름 2.7 mm, 간격 58 x 49 mm, 모서리에서 3.5 mm
        카메라커넥터 22핀 0.5 mm 피치 MIPI 2개 (CAM/DISP 겸용)
        전원       USB-C 5V 5A 권장 (5V 3A PD면 USB 주변기기 전류 제한됨)
        발열       액티브 쿨러/팬 사용 시 상부 약 10 mm 여유 + 통풍구 필요

        카메라     호환 Raspberry Pi Camera Module 3 (IMX708, 12MP, 자동초점)
                   판매 표기: "와이드 / 광각 75도" → 실측 화각 확인 필요
                   (공식 표준 75도, 공식 Wide 120도)
        카메라보드 25 x 24 mm, 두께 약 11.5 mm (Wide 약 12.4 mm)
        장착홀     M2 4개, 홀 지름 2.2 mm, 간격 21 x 12.5 mm
        케이블     카메라 15핀 1 mm ↔ Pi 5 22핀 0.5 mm 변환 FFC 필요
                   (동봉 케이블 2종 중 22핀 쪽 사용)
  보드     JPEG만 전송. fillPercent 미전송. 주기=보드 결정.
  Role
    imageRole=original → baseline.jpg 덮어쓰기, fill%=0
    imageRole=sample   → samples/ 큐(최대 10) → vision → fill%
                       → 밀림은 trash/(최대 20) → 초과 삭제
  저장
    /backend/uploads/{serial}/baseline.jpg
    /backend/uploads/{serial}/samples/*.jpg
    /backend/uploads/{serial}/trash/*.jpg

  MQTT 원본
    { "moduleSerial":"r1", "imageRole":"original",
      "imageBase64":"...", "imageFormat":"jpg" }

  MQTT 샘플
    { "moduleSerial":"r1", "imageRole":"sample",
      "imageBase64":"...", "imageFormat":"jpg" }

  r1 보드 검증 (현재 펌웨어 태그 계열 fill-100)
    data/images/001.jpg … 100.jpg
    001만 original, 002–100 sample, 10초 간격 루프
    pio run -t uploadfs && pio run -t upload

  PC 테스트
    python scripts/r1_mqtt_test.py --original
    python scripts/r1_mqtt_test.py --count 10

           D·R 상시 전원. 서버 통신 없음.
           야외 적재함 부착 시 케이스·마운트는 전부 저가 PETG 출력.

           보조배터리 (채택)

             모델: TL30T 계열
             출력: 65W PD (USB-C 등)
             외형: 약 168 × 79 × 33 mm, 약 640 g
             용도: POWER TANK 본체. 상면(168×79)에 USB-C 태양광 패널 얹어
                   야외 충전 보강 예정.
