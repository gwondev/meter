METER 명세서
갱신: 2026-09-02
서비스: https://meter.gwon.run
저장소: https://github.com/gwondev/meter


────────────────────────────────────────
기능 한눈에
────────────────────────────────────────

  AI 챗봇
    모듈 DB(적재율·신호)를 바탕으로 자연어 질의응답.

  AI 카메라
    사진으로 쓰레기 품목 분류(Gemini) → 투입·리워드 연동.

  지도
    카카오맵에 모듈 위치·적재율(0~100%)·신호 상태 표시.
    M/D(높이)=모듈 아이콘, R(카메라)=카메라 아이콘.

  최적 수거 경로
    화면 안 모듈 전부 방문. 만재 우선 정렬 + 도로망 경로.
    도로가 모듈 앞에서 끊기면 직선으로 잇고, 진행 방향 화살표 표시.

  관리자
    모듈·더미·유저 관리, 무신호 정리, MQTT 진단.

  공통 지표
    fillPercent 0~100 (0=수거 불필요, 100=즉시 수거).
    높이(cm) 원본은 웹에 안 보여 줌.


────────────────────────────────────────
D모듈 — 높이 측정 (구현 완료)
────────────────────────────────────────

  상태
    구현 완료. 펌웨어·서버·웹 연동까지 동작 중.

  GitHub
    https://github.com/gwondev/meter
    소스: meter_iot/src/module1.cpp

  역할
    초음파(HC-SR04P)로 빈 거리를 재고, 보드에서 0~100%로 환산해 전송.

  시리얼
    m1, m2, … (접두어 m)

  전송 (MQTT)
    URI      ws://mqtt-meter.gwon.run:80
    Topic    meter/{serial}/status   예: meter/m1/status
    주기     30초
    Payload  { "moduleSerial":"m1", "fillPercent":72.5 }
    QoS 1 / retain false / 구독 없음(발행만)


────────────────────────────────────────
R모듈 — 카메라 영상 판정 (인수 예정)  ★핵심
────────────────────────────────────────

  상태
    인수 예정. 아래 계약만 지키면 웹·서버와 붙는다.
    판정 알고리즘(원본↔현재 비교)은 담당자 자유.

  보드
    Raspberry Pi 5 + CSI 카메라. 시리얼 r1, r2, …

  해야 할 일 (3가지)
    1) 설치/수거 직후 「빈 상태」원본 사진 1장 로컬 보관
    2) 5분마다 현재 촬영 → 원본 비교 → fillPercent 0~100 산출
    3) 서버에 HTTPS로 보고 (수치 + 가능하면 사진)


  [필수] HTTP 사진·수치 업로드  ← 본선

    URL
      https://meter.gwon.run/api/device/modules/{serial}/report
      예) https://meter.gwon.run/api/device/modules/r1/report

    인증 헤더
      X-METER-DEVICE-TOKEN: <토큰>
      ※ 토큰 값은 노션에서 별도 확인 (이 문서에 적지 않음)

    주기
      5분 (300초)

    방식 A — 사진 포함 (권장)
      Content-Type: multipart/form-data
      필드 fillPercent : 0~100 숫자 (필수)
      필드 image       : jpg/jpeg/png/webp (선택, 최대 12MB)

    방식 B — 수치만
      Content-Type: application/json
      { "fillPercent": 72.5 }

    성공(200) 예
      {
        "ok": true,
        "serialNumber": "r1",
        "fillPercent": 72.5,
        "imageUrl": "/api/uploads/r1/….jpg",
        "lastSignalAt": "…"
      }
      사진 공개 URL: https://meter.gwon.run/api/uploads/r1/….jpg

    오류
      400  fillPercent 문제
      401  토큰 불일치 (노션 토큰 재확인)
      503  서버 토큰 미설정


  [선택] MQTT 생존·수치만  ← 사진 불가, 필수는 아님

    URI      ws://mqtt-meter.gwon.run:80
    Topic    meter/{serial}/status   예: meter/r1/status
    Payload  { "moduleSerial":"r1", "fillPercent":72.5 }
    QoS 1 / retain false
    ※ 사진은 MQTT로 못 보냄. 지도 스냅샷이 필요하면 반드시 HTTP.


  스모크 테스트

    curl -X POST "https://meter.gwon.run/api/device/modules/r1/report" \
      -H "X-METER-DEVICE-TOKEN: (노션의 토큰)" \
      -F "fillPercent=50" \
      -F "image=@./sample.jpg"

    → 200 + ok:true, 지도에 카메라 마커·적재율 보이면 성공.
    → 12분 이상 미보고 시 「신호 대기중」.


  하지 않아도 되는 것
    지도 UI / 경로 / 로그인 / DB 스키마
    모듈 사전 등록 (첫 보고 시 서버 자동 생성)
    위치 전송 (관리자 화면에서 지정)


  최소 Python 골격

    import os, time, requests
    SERIAL = "r1"
    URL = f"https://meter.gwon.run/api/device/modules/{SERIAL}/report"
    TOKEN = os.environ["METER_DEVICE_TOKEN"]   # 노션 값

    while True:
        jpeg = capture()                 # 구현
        fill = estimate_fill(jpeg)       # 0~100, 구현
        requests.post(
            URL,
            headers={"X-METER-DEVICE-TOKEN": TOKEN},
            data={"fillPercent": f"{fill:.1f}"},
            files={"image": (f"{SERIAL}.jpg", jpeg, "image/jpeg")},
            timeout=30,
        ).raise_for_status()
        time.sleep(300)

POWER TANK
────────────────────────────────────────

  보조배터리로 D모듈·R모듈(및 관련 보드)을 충전·상시 전원 공급.
  권장: 20000mAh / 100W급 이상. (뚜껑 태양광은 보조 충전용)
  서버·웹과 직접 통신하지 않음.
