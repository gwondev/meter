METER 명세서

갱신: 2026-09-02
서비스: https://meter.gwon.run
저장소: https://github.com/gwondev/meter

────────────────────────────────────────
기능 한눈에
────────────────────────────────────────

**AI 챗봇**
모듈 DB(적재율·신호)를 바탕으로 자연어 질의응답.

**AI 카메라**
사진으로 쓰레기 품목 분류(Gemini) → 투입 위치 안내

**지도**
카카오맵에 모듈 위치·적재율(0~100%)·신호 상태 표시.
M/D(높이)=모듈 아이콘, R(카메라)=카메라 아이콘.

**최적 수거 경로**
화면 안 모듈 전부 방문. 만재 우선 정렬 + 도로망 경로.
도로가 모듈 앞에서 끊기면 직선으로 잇고, 진행 방향 화살표 표시.

**관리자**
모듈·더미·유저 관리, 무신호 정리, MQTT 진단.

**★공통 지표**
**fillPercent** 0~100 (0=수거 불필요, 100=즉시 수거).
     ㄴ모듈 단에서 수거를 해야하는지의 대한 수치를 자체적으로 계산 해서 전송한다.

────────────────────────────────────────
D모듈 — 높이 측정 (구현 완료)
────────────────────────────────────────

상태
구현 완료. 펌웨어·서버·웹 연동까지 동작 중.

GitHub
https://github.com/gwondev/meter
소스: meter_iot/src/module1.cpp

역할
초음파(HC-SR04P)로 빈 거리를 재고, 보드에서 0~100%로 환산해 전송.

시리얼
m1, m2, … (접두어 m)

전송 (MQTT)
URI      ws://mqtt-meter.gwon.run:80
Topic    meter/{serial}/status   예: meter/m1/status
주기     30초
Payload  { "moduleSerial":"m1", "fillPercent":72.5 }
QoS 1 / retain false / 구독 없음(발행만)

────────────────────────────────────────
POWER TANK
────────────────────────────────────────

보조배터리로 D모듈·R모듈(및 관련 보드)을 충전·상시 전원 공급.
권장: 20000mAh / 100W급 이상. **(뚜껑 태양광은 보조 충전용)**
서버·웹과 직접 통신하지 않음.

────────────────────────────────────────
R모듈 — 카메라 판정 (인수 예정)  ★핵심
────────────────────────────────────────

**상태**
인수 예정. D모듈과 같은 MQTT 쓴다

**보드**
Raspberry Pi 5 + CSI 카메라. 시리얼 r1, r2, …

**보드에서 할 일**
1) 모듈에는 고유 원본 사진이 저장(말끔히 치워진 상태)
(예: 5장. 사람·차 등 일시 물체를 걸러 내려면 다중 원본 비교가 필요할 수 있음)
2) 1분마다 현재 사진 촬영 → 원본들과 비교해 fillPercent 산출(로컬)
3) 5분마다 MQTT로 fillPercent + 압축 이미지 전송

**웹·서버**
R 모듈 클릭 → 가장 최근 수신 이미지 표시 (lastImageUrl)
모듈당 최근 20장만 디스크에 보관 (초과분 삭제)

**MQTT (D와 동일 브로커·토픽)**

```
URI      ws://mqtt-meter.gwon.run:80
Topic    meter/{serial}/status   예: meter/r1/status <- **r1**으로 구현하면된다. 라즈베리파이 2개째 부터 r2
주기     5분 (촬영·비교는 1분, 전송만 5분)
QoS      1 / retain false
인증     없음
패킷 한도 브로커 2MB (압축 JPEG + base64)
```

페이로드 — 수치만

```
{ "moduleSerial":"r1", "fillPercent":72.5 }
```

페이로드 — 수치 + 사진 (권장)

```
{
  "moduleSerial": "r1",
  "fillPercent": 72.5,
  "imageBase64": "<JPEG base64>",
  "imageFormat": "jpg"
}

사진: JPEG 압축 200~500KB 권장. 서버 디코드 상한 약 900KB.
```
